القاعدة: main c765c82f29d69f69c4abb492ec13b7bedda28c24. لا تعديل VERSION/BUILD (0.3.0/8)، ولا إعلان Release Seal.

## عيوب ثبتت من المصدر

- كان statusString وobservatorySnapshot ينشئان وينسخان EngineCore كاملًا؛ واستدعاهما HUD معًا كل 0.75 ثانية. أصبح HUD يقرأ snapshot خفيفة فقط، والمرصد يلتقط مدخلات تشخيصية bounded دون نسخ world/AI/Black Box. منع نسخ EngineCore وقت الترجمة.
- hashing وفحص سلسلة Integrity وترتيب percentiles تجري بعد تحرير core lock. اللقطة تحمل بيانات متسقة من لحظة واحدة، ولا تتغير بعد تقدم المحاكاة أو reset. حجم اللقطة محدود باختبار 192 KiB؛ هذا تخفيض نسخ وليس zero-copy.
- قياسات capture wait/held/finish تخص آخر طلب رصد، وليست متوسط الجلسة أو تكلفة CPU خالصة. تشمل held كلفة فك القفل؛ لا يجوز نسبتها إلى simulation slice.
- شرط 32 AI القديم مستحيل بعد اعتماد 31 AI + اللاعب. التغطية الجديدة تقيس مدة وجود 32 مقاتلًا قادرًا، ومدة تزامنهم مع 64 مقذوفًا على الأقل. لا تتراكم من tick مكرر أو catch-up clamped. القياس محافظ عند حدود callbacks ولا يدعي قياس كل slice داخل callback.
- المصدر الحقيقي يختم في Info.plist أثناء بناء IPA من git rev-parse HEAD، مع تحقق مطابقته بعد Xcode. البناء اليدوي غير المختوم يظهر UNSTAMPED. هذا تعريف مصدر، وليس ضمانًا ضد تعديل الحزمة عند التوقيع.

## الاختبارات الآلية وحدودها

TelemetryCaptureTests يختبر ثبات اللقطة، إعادة استخدامها بعد reset، التفاف Black Box، حجمها، ومنع نسخ مالك المحاكاة. اختبارات coverage تغطي الحدود والتكرار والتعليق.

test_engine_soak.sh يشغل ساعتين **من زمن المحاكاة** على مضيف CI/Linux، وليس ساعتين على آيفون. يشغل نسختين مستقلتين من النواة الحقيقية للاختبار ويقارن hash دوريًا، مع 32 مقاتلًا مُنشأً، ومقذوفات اصطناعية bounded تصل إلى 96، وجولات reset صريحة كل 120 ثانية. لا تعطيل للضرر أو تعديل للصحة؛ موت اللاعب قد يجعل مدة الحمل القتالي الكامل قصيرة، ويطبعها الاختبار كما هي. الاختبار ليس إثبات قتال كامل مستمر لساعتين.

يفحص invariants وrollback ويعد استدعاءات ordinary C++ new/new[] داخل التشغيل. لا يغطي malloc المباشر أو aligned allocations أو تسربات Metal/Swift أو حرارة الجهاز. المصدر المطبوع محليًا قبل commit يشير إلى القاعدة؛ المرجع النهائي هو SHA رأس CI المطابق للشجرة المختبرة.
