# الجدار الوقائي

أي إصدار لا يمر بكل البوابات لا ينتج Artifact معتمد.

## بوابات قبل Unreal
- SHA-256 لكل ملف مصدر.
- منع ملفات الشهادات والمفاتيح.
- منع Nanite/Dynamic GI في baseline.
- تثبيت حد المقاتلين 32.
- منع Tick غير مصرح.
- تثبيت 60 FPS هدف و30 FPS حماية.

## بوابات Unreal
- Compilation على بيئة المحرك الفعلية.
- Automation tests باسم METSE.*.
- Cook/Stage/Package iOS.
- عدم إنشاء IPA إذا لم ينتج .app حقيقي.

## التوقيع
لا تُحفظ شهادة المستخدم أو provisioning profile في المستودع. ملف IPA الناتج من هذا المسار مقصود أن يكون غير موقّع، والتوقيع يتم خارج المستودع بواسطة المستخدم.
