# METSE Gateway Design

البوابة مبنية كـCommand Hub وليس قائمة طويلة.

## الطبقة الأولى
- اسم المشروع وحالة المحرك.
- زر رئيسي واحد: `ابدأ جلسة تكتيكية`.
- حالة Build/Engine/Content في chips صغيرة.

## الطبقة الثانية
- التدريب
- العمليات
- العتاد
- مركز التحديث
- الإعدادات
- التشخيص

كل وحدة Card كبيرة ذات icon + عنوان + وصف، قابلة للإضافة لاحقًا من Model واحد.

## قواعد ثابتة
- لا زر تفاعلي أصغر من 44pt.
- Safe Area إلزامية.
- Press state واضح.
- لا autoplay audio/video في البوابة.
- لا إجبار على حساب/تسجيل دخول لأن اللعبة الخاصة لا تحتاج حسابًا.
- branding هادئ؛ لا نكرر الشعار على كل شاشة.
