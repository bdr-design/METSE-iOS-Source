# METSE 0.2.0 Build 007 — الحزمة الكبيرة الأولى

هذا الإصدار يثبت سياسة التطوير الجديدة: إصدار أقل تكراراً، لكن بحزمة مترابطة أكبر تمر بالكامل عبر Source Integrity وGuardrails واختبارات C++ وSwift وXcode وIPA.

## 1. Character Feel
- حالات حركة مستقلة: Idle / Walk / Tactical / Jog / Sprint / Crouch / Crawl.
- تسارع وتباطؤ مستمر بدلاً من القفز اللحظي في السرعة.
- فصل اتجاه الجسم عن اتجاه النظر.
- Camera bob وroll خفيفان مرتبطان بالمشية والسرعة.
- Landing offset عند الهبوط القوي.
- ارتفاع كاميرا متدرج للوقوف والقرفصاء والانبطاح.

## 2. World Collision Foundation
- WorldCollisionCore مستقل ومحمول C++.
- حدود عالم ثابتة ومتحقق منها.
- عوائق AABB بميزانية ثابتة لا تكبر أثناء اللعب.
- تصحيح X ثم Z للسماح بالانزلاق على الجدار بدلاً من إيقاف الحركة بالكامل.
- نصف قطر اللاعب مصدره CharacterConfig.
- نفس footprints القادمة من C++ تُرسل إلى Metal للرسم؛ لا توجد نسخة مستقلة لمواقع الجدران داخل Swift.

## 3. مركز الأرصاد
مركز رصد حي يعمل أثناء الجلسة ويقرأ فقط من المحرك ولا يملك gameplay state.

يرصد:
- FPS التقديري، AVG/P95/MAX frame time.
- Frames فوق 20ms و33ms.
- Catch-up clamps.
- المسافة المقطوعة والسرعة القصوى.
- وقت Sprint وAirborne.
- انتقالات الوضعية والمشية.
- تصادمات العالم وعدد العوائق.
- سلامة Journal وControl Plane وRollback.
- Black Box وحجم event/command ledgers.
- عدد Metal frames وdrawable misses وCPU encode time.
- الحالة الحرارية من iOS.

يوفر زر نسخ وزر مشاركة لتصدير تقرير نصي تقني كامل يمكن إرساله مباشرة للمراجعة.

## 4. التحكم
- عصا حركة ديناميكية مرئية بدلاً من منطقة لمس غير مرئية.
- زر مباشر لمركز الأرصاد داخل جلسة اللعب.
- زر Sprint يعطي feedback بصري أثناء الضغط.
- أيقونة الوضعية تتحدث حسب حالة اللاعب.

## قواعد الحزمة
- لا WebView داخل المحرك.
- لا Unreal.
- C++ هو مصدر حقيقة المحاكاة.
- Metal presentation فقط.
- كل external gameplay mutation يمر عبر Control Plane الذري.
- كل ring buffer محدود السعة.
- التحديثات الداخلية مؤجلة إلى ما بعد اكتمال بناء اللعبة الأساسي.
