# Build 011-C — الخصوم الأصليون داخل المشهد

## ما تغير فعليًا

- أزيل رسم الخصوم كأشكال ثنائية الأبعاد داخل ممر السماء.
- أضيف `METSECombatantRenderer` لرسم جسم تكتيكي مركب كشبكة مثلثات مفهرسة ومكررة بالـinstancing داخل Metal.
- كل نسخة تربط ثلاثة مصادر سلطوية بعد مطابقة `id`: الموضع والصحة وحالة القتال من `DamageCore`، الاتجاه والفعل من `TacticalAICore`، ومستوى العرض وخط النظر من `VisibilityCore`.
- الخصم الآن يدخل اختبار العمق نفسه مع الأرض والمباني والسلاح، لذلك تحجبه هندسة العالم بصريًا.
- حالات العجز والموت تغيّر وضع الجسم، وأفعال الحركة تضيف حركة عرض محدودة لا تعيد كتابة حالة المحاكاة.
- مخزن النسخ محدود بـ32 خصمًا وثلاثي التخزين، ولا يُعاد استخدامه قبل اكتمال command buffer.

## ترتيب الرسم

1. السماء والمقذوفات والمؤثرات.
2. أرض وهندسة ساحة المعركة.
3. الخصوم ثلاثيو الأبعاد.
4. سلاح منظور الشخص الأول.
5. شبكة التصويب ووميض الفوهة.

## حد الجودة الحالي

الشبكة الجديدة بديل هندسي أصلي للعلامات ثنائية الأبعاد، وليست أصل الجندي النهائي. تتضمن جسمًا كاملًا وخوذة وسترة وسلاحًا وأطرافًا، لكنها لا تحتوي بعد على هيكل عظمي أو skinning أو IK أو خامات PBR فنية. بوابة الجودة التالية هي استبدالها بأصل مرخص ومهيكل مع LOD وأنيميشن، مع بقاء عقد البيانات والعمق والـinstancing الحالي أساسًا للتحميل والعرض.
